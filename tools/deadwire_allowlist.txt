# deadwire allowlist
#
# Declarations that `tools/deadwire.py` reports as unreferenced, and that a
# person has looked at and judged safe. One `File.swift:name  # reason` per
# line. Anything the detector finds that is NOT on this list fails CI.
#
# The reason column is the point of the file. It is the record that somebody
# actually opened the source, and it is what the next person reads instead of
# re-deriving the answer. A line with no reason is not triage.
#
# THREE VERDICTS were used when this list was built, on 2026-09-06, across all
# 113 entries:
#
#   ARTEFACT  the detector is wrong. The name IS used, but only inside a string
#             literal, and strings are stripped before counting. Or it is a
#             Swift mirror of a Metal struct, which Swift must never name.
#   HARMLESS  genuinely unreferenced, and nothing was supposed to happen. A
#             spare helper, a convenience property, a wire-contract field.
#   REAL      a feature the app was designed to do and does not, because the
#             code that would do it is never reached. NONE of these are on this
#             list. All of them were WIRED UP instead. That is the rule: fix by
#             wiring, not by allowlisting.
#
# Adding a line here is a decision, not paperwork. If the honest answer to
# "what feature silently does not happen?" names a feature, this file is the
# wrong place for it.
